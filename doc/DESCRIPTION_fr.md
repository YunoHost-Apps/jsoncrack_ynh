JSON Crack est un outil pour visualiser des données JSON, YAML, CSV et XML sous forme de graphes interactifs, rendant ces fichiers plus facile à explorer, à formater et à valider. Il inclut les fonctionnalités suivantes:
- Visualisateur: Transformez instantanément des données JSON, YAML, CSV et XML en graphes interactifs ou en arbres de données avec un thème sombre et un thème clair.
- Convertisseur: Passez d'un format à un autre afin de le partager sous la forme voulue.
- Validateur: Mettez en forme et vérifiez la validité des données JSON, YAML et CSV pour obtenir des données claires et précises.
- Générateur de code: Générez automatiquement le code pour des interfaces TypeScript, des structs Golang, des classes de données Kotlin, des types Rust Serde, et des schémas JSON.
- Schémas JSON: Créez des schémas JSON valides.
- Outils avancés: Exécutez de requêtes jq ou JSON path.
- Export d'image: Téléchargez les visualisations sous forme d'images PNG, JPEG ou SVG.
- Confidentialité: Traitement des données côté client, rien n'est enregistré sur le serveur.
